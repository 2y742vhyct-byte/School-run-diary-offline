# School Run Diary — Offline

Free, offline-first school run diary for an iPhone. The public repository contains **app code only**, not any real passenger names, contact information, attendance, saved photos or school records.

## Open the app

Once GitHub Pages has been enabled for the main branch, open the Pages URL in Safari, use Share > Add to Home Screen, and open it once while online. It will cache the app files for subsequent offline access. Create a passphrase and download encrypted backups regularly; browser storage can be cleared when removing website data or apps. Do not upload backups or operating-board photographs to GitHub.

## Privacy and limitations

Records and photographs are stored locally and encrypted with your chosen passphrase in IndexedDB; they do not sync across devices. Opening the app on another device starts a separate diary unless you restore an encrypted backup. There is no password recovery. This first version offers manual board-photo entry, not automatic OCR.
